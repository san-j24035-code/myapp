# COOK MENU

Recipe suggestions are generated by OpenRouter through the `/api/recipe` Cloudflare Pages Function. The API key is used only on the server and must not be added to client code or committed to the repository.

## Cloudflare Pages configuration

In the Cloudflare Pages project, add these environment variables under **Settings → Variables and Secrets**:

- `OPENROUTER_API_KEY` — required; store as a secret.
- `OPENROUTER_MODEL` — optional; defaults to `openai/gpt-4o-mini`. Use an OpenRouter model ID if you want to change models.

Redeploy the Pages project after changing these variables. Recipe generation does not substitute a static template if the AI request fails; the app displays the error so the configuration or service issue can be addressed.

The app must be served with Cloudflare Pages Functions enabled. A static-only host such as GitHub Pages does not provide the `/api/recipe` endpoint.
